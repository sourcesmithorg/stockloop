# StockLoop / Cornerstore HTML templates

A portable, high-fidelity UI template kit for an inventory purchasing copilot. **Static HTML and CSS only.** No JavaScript, framework, dependency installation, build process, server, or API is needed to open it.

## Start here

1. Unzip the archive.
2. Open `stockloop-html-template/index.html` in a current browser.
3. Use the navigation to explore the app screens.
4. Open `states.html` for 40 reusable state examples and `components.html` for the shared visual vocabulary.
5. For the registration flow, start at `register.html`, then `onboarding.html`.

All assets are bundled locally, including fonts and SVG illustrations. The templates work offline. Use your browser's Print command on `order.html` to inspect the purchase-order print layout.

## Presentation behavior, not business behavior

Links navigate between authored fixtures. Native `<details>` opens the mobile menu, filters, and reasoning. Native select, checkbox, number, text, and file controls can be changed visually.

**Nothing is imported, calculated, authenticated, saved, translated, converted, approved, generated by AI, exported by an application, emailed, or purchased.** In particular:

- Changing a quantity or budget does not update the displayed sample totals.
- Selecting a CSV does not upload or read it. The next link opens a seeded mapping fixture.
- The CSV download links serve bundled sample files, not reports generated from user data.
- The success and approval screens are explicitly labeled examples, not evidence of a completed action.
- Do not enter real credentials into the auth templates. They have no submit mechanism.
- The document is not a real purchase order. Browser printing is CSS presentation only.

This deliberate boundary makes the markup easy to slice while leaving all application logic to your team.

## International setup

English and USD are the defaults. Onboarding and settings include 249 ISO country/territory options, 154 current tender-currency choices, 35 language choices, and IANA timezone options.

These are selectable template choices, **not implemented translations, region inference, or currency conversion**. Countries and currencies are independent; the application must apply supported locales, formatting, translation resources, timezone rules, rounding and exchange-rate policy. Historical orders must retain their original currency. See `HANDOFF.md` for the integration contracts.

## Visual system

Cornerstore: warm mineral-paper surfaces, charcoal type, terracotta primary actions, and sage/amber/clay semantic states. Locally hosted DM Sans, fixed product-UI typography, tabular numbers, logical CSS properties, reduced-motion support, native controls, and inline explanations.

Desktop, tablet, and mobile layouts are provided. Dense tables intentionally scroll inside their own labeled, keyboard-focusable region; they do not enlarge the whole page. Text labels accompany status colors.

## Browser support and verification

Designed for current evergreen browsers with CSS Grid and OKLCH support. Verification results and explicit limitations are recorded in `QA.md`. Real-device and cross-browser integration testing remain your team's responsibility. The template uses only local references and contains no analytics or network calls.

## Slicing

See `HANDOFF.md` for component boundaries, state hooks, fixture routes to replace, and required logic. You may port the markup to any frontend stack without changing the design system. Avoid shipping fixture-success links as real actions.
